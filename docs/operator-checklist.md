# Operátori ellenőrzőlista / Operator checklist

Print this page. Hungarian first, English below each line. (Draft translation: owner proofreads.)

## Egyszer, a gépen / Once, on the Mac

1. **Automatikus frissítés kikapcsolva.** Rendszerbeállítások > Általános > Szoftverfrissítés > Automatikus frissítések: minden ki.
   Automatic updates off. System Settings > General > Software Update > Automatic updates: all off.
2. **Fekete háttérkép minden kijelzőn**, a projektoron is. Rendszerbeállítások > Háttérkép > fekete szín.
   Black wallpaper on every display, the projector included. System Settings > Wallpaper > black colour.
3. **"A kijelzők külön Spaces-ben" bekapcsolva** (alapértelmezés). Rendszerbeállítások > Asztal és Dock.
   "Displays have separate Spaces" on (default). System Settings > Desktop & Dock.

## Minden előadás előtt / Before every show

1. **Töltő bedugva.** / Power adapter plugged in.
2. **Projektor HDMI bedugva, a projektor be van kapcsolva.** / Projector HDMI plugged in, projector on.
3. **Projektor frissítési gyakoriság:** Rendszerbeállítások > Kijelzők > projektor > Frissítési gyakoriság: 23,98 / 24, vagy 47,95 / 48, vagy 71,93 / 72 Hz, ha van; különben 60 Hz.
   Projector refresh rate: System Settings > Displays > projector > Refresh rate: 23.98 / 24, or 47.95 / 48, or 71.93 / 72 Hz if offered; else 60 Hz.
4. **Ne zavarjanak (Fókusz) bekapcsolva.** Vezérlőközpont > Fókusz > Ne zavarjanak.
   Focus / Do Not Disturb on. Control Centre > Focus > Do Not Disturb.
5. **Minden más program bezárva** (Üzenetek, Mail, böngésző).
   Every other app closed (Messages, Mail, browser).
6. **Tartalék gép kész:** régi laptop bekapcsolva, 00-ás klip előkészítve, HDMI kapcsoló az új gépen.
   Backup ready: old laptop on, clip 00 ready, HDMI switch on the new Mac.
7. **Program indítása.** A projektor fekete. Lent: "Minden rendben". Fent: projektor neve zöld, NÉMÍTVA.
   Start the app. Projector black. Bottom line: "All good". Top: projector name green, MUTED.
8. **Koncert mód:** kattints kétszer a Koncert gombra. Nagy KONCERT felirat.
   Concert mode: click Concert twice. Big CONCERT banner.

## Előadás közben / During the show

| Gomb / Key | Mit csinál / What it does |
|---|---|
| Enter | GO: a következő a projektorra / next item onto the projector |
| B | Fekete takarás be/ki (a klip fut tovább) / Black cover on/off (clip keeps running) |
| L | Logó takarás be/ki / Logo cover on/off |
| Szóköz / Space | Lejátszás / szünet / Play / pause |
| ← → | 5 mp tekerés / Seek 5 s |
| ↑ ↓ | Előző / következő előkészítése / Arm previous / next |

## Ha baj van / If something goes wrong

- **A projektoron asztal látszik, vagy eltűnt a program:** kapcsold a HDMI kapcsolót a tartalék gépre. Utána indítsd újra a programot; fekete képpel indul, és mutatja, hol tartott.
  Desktop on the projector, or the app vanished: flip the HDMI switch to the backup laptop. Then restart the app; it starts black and shows where it was.
- **Piros sáv: "A billentyűk nem az apphoz mennek":** kattints a piros sávra.
  Red bar "Keys are not reaching the app": click the red bar.
- **Rossz kép a projektoron:** B (fekete), válaszd ki a jót (↑ ↓), Enter.
  Wrong picture on the projector: B (black), arm the right one (↑ ↓), Enter.

## Előadás után / After the show

Cmd+Q kétszer, 3 másodpercen belül. / Cmd+Q twice within 3 seconds.
